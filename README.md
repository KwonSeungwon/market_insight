# Market Insight

**제품 아이디어를 시장·경쟁상품·고객 니즈의 근거와 함께 검토하는 웹 서비스입니다.**

제품 콘셉트와 목표 고객, 판매 채널을 입력하고 참고 자료를 첨부하면 시장 조사와 상품 비교, 고객 분석을 한 프로젝트에서 검토할 수 있도록 설계합니다. 결과를 수정하고 확정한 뒤 텍스트와 표, 차트를 개별 편집할 수 있는 PPTX로 내보내는 것이 목표입니다.

## 해결하려는 문제

신제품을 기획할 때는 통계와 판매처, 리뷰, 참고 문서에 흩어진 자료를 모아야 합니다. 자료마다 조사 시점과 품목 정의가 달라 비교하기 어렵고, 분석 결과를 발표 자료로 옮기는 작업도 반복됩니다.

Market Insight는 분석 결과와 출처를 연결하고 사실과 가설을 구분해 제품 기획자가 판단에 필요한 근거를 확인하도록 돕습니다. 출시 여부를 자동으로 승인하거나 하나의 종합점수로 결론을 내리지 않습니다.

## 주요 기능

아래는 웹 서비스가 목표로 하는 기능입니다.

| 기능 | 설명 |
|---|---|
| 제품 및 분석 범위 설정 | 제품 콘셉트, 원재료, 용량, 목표 고객, 판매 채널과 비교 범위를 입력합니다. |
| 참고 자료 첨부 | 문서에서 추출한 내용을 확인하고 잘못 읽은 값은 수정하거나 제외합니다. |
| 국내 시장 분석 | 시장 규모와 흐름을 출처, 기준 시점, 품목 정의, 단위와 함께 검토합니다. |
| 경쟁상품 비교 | 가격과 용량, 단위 가격, 제품 특성, 판매 채널과 고객 반응을 비교합니다. |
| 고객 니즈 및 세그먼트 분석 | 고객이 직접 표현한 요구와 추정한 잠재 니즈를 구분하고 구매 목적과 사용 상황으로 세그먼트를 정의합니다. |
| 제품 경쟁력 검토 | 시장과 경쟁상품, 고객 분석을 연결해 차별화 근거와 취약 요소, 추가 검증 항목을 확인합니다. |
| 목표 매출 계산 | 온라인·오프라인·B2B별 가격과 목표 수량으로 채널별 매출과 합계를 계산합니다. |
| 결과 편집 및 PPTX 내보내기 | 사용할 내용을 선택하고 최종 확정한 결과를 편집 가능한 발표 자료로 만듭니다. |

## 사용 흐름

1. 제품 정보를 입력하고 분석 범위를 정합니다.
2. 참고 자료를 첨부하고 추출 결과를 확인합니다.
3. 분석 결과와 원문 근거, 불확실성을 검토합니다.
4. 목표 매출을 계산하고 결과를 수정·확정합니다.
5. 확정한 결과를 PPTX로 내려받습니다.

## 분석 원칙

- **근거를 추적합니다.** 주요 주장에는 출처와 기준 시점, 신뢰도 또는 근거 부족 상태를 표시합니다.
- **사실과 가설을 구분합니다.** 잠재 니즈와 추정 세그먼트에는 가설 표시와 검증 방법을 붙입니다.
- **불확실성을 숨기지 않습니다.** 자료가 없거나 서로 충돌하면 그 상태와 판단의 한계를 보여줍니다.
- **계산을 재현할 수 있게 합니다.** 수치의 입력값과 계산식을 표시합니다. 가격이나 수량이 없으면 매출을 임의로 계산하지 않습니다.
- **최종 판단은 사용자가 합니다.** 목표 매출은 사용자가 입력한 판매 목표이며 시장 수요 예측값이 아닙니다.

## 목표 매출 계산

기본 산정 기간은 1년이며 채널별 가격과 목표 수량을 따로 입력합니다.

```text
온라인 목표 매출 = 온라인 판매가 × 온라인 목표 수량
오프라인 목표 매출 = 오프라인 판매가 × 오프라인 목표 수량
B2B 목표 매출 = B2B 공급가 × B2B 목표 수량
총목표 매출 = 계산 가능한 채널별 목표 매출의 합계
```

계산되지 않은 채널은 합계와 함께 표시합니다. 할인과 반품, 수수료, 원가를 반영한 손익 분석은 초기 범위에 포함하지 않습니다.

## 개발 상태

현재는 호스팅형 웹 서비스로 전환하기 위한 준비 단계입니다. 이 저장소에는 프로젝트 소개 문서만 있으며 실행 가능한 웹앱과 배포 주소는 아직 없습니다.

기존 로컬 프로토타입에서 개발한 제품 검증, 자료 추출, 데모 분석, 목표 매출 계산과 PPTX 생성 로직을 재사용할 예정입니다. 기존 분석 공급자는 데모 데이터를 사용하며 실제 외부 검색·수집 기능은 아직 연결되지 않았습니다.

다음 개발 범위는 웹 화면과 서버 API, 사용자 인증과 프로젝트별 접근 제어, 데이터 저장 및 분석 공급자 연결입니다. 외부 자료의 이용 조건과 지원 파일 규격은 운영 환경에 맞춰 확정합니다.
